# Prisma

Produto de dados para inteligência e performance de uma rede de parceiros comerciais de uma empresa SaaS B2B, desenvolvido para portfólio com dados sintéticos/fictícios.

## Escopo

- Simulação de um cenário de negócio com dados sintéticos/fictícios.
- Nenhum dado real, código proprietário ou infraestrutura da empresa original é usado ou acessado.

## Documentação

- [Especificação do produto](docs/product-spec.md)
- [Regras de negócio (metodologia V1)](docs/business-rules.md)

## Dados

O Prisma não possui schema ou migrations Supabase próprios. Ele depende do projeto Supabase compartilhado do ecossistema, cujo schema/migrations vivem em `supabase/` na raiz do repositório.

A estrutura interna deste produto (aplicação, documentação técnica) será definida conforme o desenvolvimento avançar.
